# Data center sites

From the permit harvest for Wisconsin dated 2026-11-17. The convention (September 2026 manual, Baird 2026-10-27): a data center backup engine fleet is a plant when the summed electrical nameplate of its generators reaches the threshold (50.0 MW). A routine-power gas or diesel plant at a data center is an add too. Capacity unknown means add with the capacity cell blank. Never a watch item for being backup. Name it "<Operator> <Place> Data Center power station", name the data center in Project Links, one unit row per permit phase or building group, fuel diesel or gas as the permit says, technology internal combustion with Number Of Engines and Capacity Per Engine from the permit, Captive industry use power, Captive industry type data center, Backup Power yes at unit level on backup units only, Captive Data Source the permit.

Answer every site below that has a task by writing batches/<tag>/coverage.json under `data_centers`, keyed by the site id: `decision` is add (with the `record_id` of the newplants record), already_in_gem (with `plant_id`), update (with the `record_id` of the updates record, when the permit disagrees with GEM), below_threshold (with `summed_nameplate_mw`, the number you added up), no_generators, not_data_center or nothing_found, plus a plain `note` saying what was read or searched. A site the harvester summed at the threshold is an add unless the note names the GEM plant that already holds the fleet. A site with no usable sum, or no document on record, is an add once you find generators; close it another way only with the number or the search you did.
