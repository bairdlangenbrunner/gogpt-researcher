# GEM document hub + SOP index

**This is the one place for links to every GEM team document this repo relies on.**
Edit it freely — add a row when a new doc appears, mark a row superseded when a
cycle rolls over. Drive links need GEM Workspace access: read them via `gws-gem`
(read-only) or the Drive MCP; this repo never modifies Drive files. The
Editing Manual and the current cycle's Update sheet are **referenced, not
copied** — the repo's `docs/reference/` distillations carry only the working
rules an agent needs at batch time, and the live doc always wins on conflict.

## SOPs in this repo (`docs/sops/`)

| SOP | file | run when |
|---|---|---|
| Update | `update.md` | working a country's (or US state's) existing plants/units in a cycle pass |
| Discovery | `discovery.md` | hunting plants/units missing from the tracker |
| Triage | `triage.md` | turning a fresh scoped pull into a prioritized worklist (incl. the 2y/4y inferred-status sweep) |
| QC | `qc.md` | batch gate before deliverables; country close-out |

Reference docs supporting them all live in `docs/reference/`; country-specific
source knowledge in `docs/country_notes/` (US states under
`docs/country_notes/united_states/`).
